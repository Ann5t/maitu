# 迁移状态

当前交付是可以真实读写现有数据的第一个 Rust 纵向版本，不宣称已经达到旧桌面版的全部功能等价。

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 旧版视觉语言 | 已完成 | 纸张底色、酸绿色强调、侧栏、紧凑卡片、明暗主题 |
| 项目总览与创建 | 已完成 | 服务端渲染与 JSON API 共用逻辑 |
| 成果契约 | 已完成 | 修订意图、确认现实完成证据 |
| 文件产物 | 已完成 | 生成、版本信息、SHA-256、审阅批准、下载 |
| 项目 DAG | 已完成 | 分支、节点、边、类型化贡献、暂停、选择性合流 |
| 现有 nextgen 数据 | 已完成 | 直接读取现有 PostgreSQL 和产物卷 |
| 移动端可用性 | 已完成 | 小屏改用可读的节点列表，表单保持完整 |
| 自动化质量门 | 已完成 | rustfmt、Clippy、单元测试和隔离 HTTP 流程 |
| 身份认证与多用户 | 未迁移 | 公开部署前必须实现 |
| CSRF 与速率限制 | 未迁移 | 与身份认证一起补齐 |
| AI 模型适配器 | 未迁移 | 当前所有动作都是确定性本地逻辑 |
| 语音输入 | 未迁移 | 旧镜像中的录音能力尚未移植 |
| 桌面原生封装 | 未迁移 | 当前目标是 Docker/Web，全 Rust 桌面壳另行评估 |
| 后台作业与实时进度 | 未迁移 | 目前动作在请求内完成 |
| 旧版零散信息架构 | 待取舍 | 不机械复制旧页面，先以项目脉络验证核心工作流 |

## 推荐后续顺序

1. 先让你按真实使用习惯验收新版视觉和项目脉络交互。
2. 增加单用户登录、会话、CSRF 和反向代理部署模板。
3. 把模型调用抽象成 Rust trait，并实现可替换提供商与调用审计。
4. 增加附件上传、孤儿产物回收和后台任务。
5. 根据旧版真实高频操作决定语音、桌面壳和其他页面是否值得迁移。
