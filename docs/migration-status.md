## 推荐后续顺序

1. 先让你按真实使用习惯验收想法投影、目标图、插件现场、文件复制/引用和多设备密度。
2. 由你选择私人网络 + 内部 CA，或公网域名 + ACME；完成异地备份后再安排遗留数据库端口维护窗口。
3. 以现有 Worker/Tool Pack 协议接入第一个真实模型提供商，单独审查凭据、费用、上下文与数据外发边界。
4. 根据旧版真实高频操作决定实时语音、桌面壳和其他页面是否值得迁移。
