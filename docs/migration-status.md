## 推荐后续顺序

1. 先让你按真实使用习惯验收新版视觉和项目脉络交互。
2. 增加单用户登录、会话、CSRF 和反向代理部署模板。
3. 把模型调用抽象成 Rust trait，并实现可替换提供商与调用审计。
4. 增加孤儿产物/上传分段回收和后台任务。
5. 根据旧版真实高频操作决定语音、桌面壳和其他页面是否值得迁移。
