## DeepSeek 长度设置修正

2026-10-01，用户指出连接页应移除超时设置，并按 DeepSeek 实际能力提供上下文与输出长度。类别为模型与执行，分支 `execution/deepseek-length-settings` 从资料任务分支建立。

连接页增加上下文预算，修正最大输出范围；随后按用户“默认还是思考”的选择，在 `execution/deepseek-thinking-default` 分支增加实际请求的思考开关，新连接默认开启，输出默认 65,536 Token。已存输出设置保留，切换模式也不会覆盖手动填写的长度。上下文按文本估算检查输入与预留输出，超出预算在请求前记录失败。输入快照的文件大小限制提高到 8 MiB，后台处理无数据等待而非使用用户填写的短总超时。参数含义、来源和估算边界维护在[本机运行说明](../operations/maitu-local.md)。

Rust 格式、Clippy、65 项单元测试与隔离资料任务检查通过；HTTP 测试接口接收到高于旧限制的输出参数，预算不够时没有发出请求。真实 Chromium 验证长度保存、刷新、空密钥更新、无超时输入、占满预算的提示与桌面和手机布局。本机标准生产镜像构建与更新成功，原有四个排队任务、各自的尝试编号与资料保留。完整质量门随此修正推送运行；本机和隔离检查不能视为真实 DeepSeek 验收。

思考模式修正的 Rust 格式、Clippy、65 项单元测试与隔离资料任务检查通过。测试接口分别收到 `thinking.type=enabled` 和 `disabled`，输入记录保留本次模式，用量记录保留思考 Token 数，成果文件没有混入推理正文。真实 Chromium 验证开启默认值、两种模式保存与刷新，以及切换模式保留填写长度和密钥；桌面与手机页面无脚本错误或服务器 500 响应。标准生产镜像构建与本机更新通过，四个排队任务的尝试编号与资料保持一致，实际连接页默认开启思考、输出上限为 65,536 Token。

2026-10-01，用户接受“读取资料并产出文件”的首轮 Goal，选择 DeepSeek。类别为模型与执行，分支为 `execution/parallel-file-tasks`，在首次修改前已从运行基线分支建立。

本机已编译并启动新版。Rust 格式、Clippy 和 62 项单元测试通过。隔离数据库迁移、重复迁移、项目与尝试引用约束通过。独立 HTTP 测试接口验证了三个请求实际重叠、429 失败隔离、手动重试、固定资料与前序版本、并发降为 1、执行器中断恢复，以及超过 128 个依赖等待任务时仍能推进独立任务。

本机真实 Chromium 表单检查通过：文件导入、任务图创建和启动、等待说明、失败与重试记录、输入查看、刷新与移动布局；没有页面脚本错误或服务器 500 响应。检查用关闭的本机端口验证网络失败，不调用付费服务。

本机标准 Docker 构建首次在 crates.io 下载超时后停止。先用缓存离线编译启动新版，再给标准构建加入 Cargo 缓存并关闭代理路径上的 HTTP 多路复用；复用本机已有依赖后，标准生产镜像构建与启动已成功。
