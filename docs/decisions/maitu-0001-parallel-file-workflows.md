# Maitu 0001：先完成可追溯的并行资料任务

日期：2026-10-01。状态：首轮范围已由用户接受，任务分支实现中。此决定定义 Maitu 本轮边界，继承的浮点产品规划继续作为历史资料。

## 背景与选择

用户希望独立工作能同时推进，项目的状态和历史能从图上理解。用户接受的本轮范围为“读取资料并产出文件”，首个模型服务为 DeepSeek。首轮不包含修改代码、运行检查和任意电脑工具。

保留 Rust、Axum、PostgreSQL、原有鉴权和成果存储，在 `src/maitu/` 增加资料任务调度，在 `src/web/maitu.rs` 与独立网页资源中提供项目图。首页进入新工作区；继承的页面从 `/legacy` 进入。任务、模型请求、产出和用户采用分别记录。

## 执行与历史

每次启动生成独立 Attempt，固定用户要求、已选资料及其校验值。没有选择资料时，使用启动当时项目中的全部资料。资料为 UTF-8 文本，单件上限 256 KiB，含前序成果的本次输入总量上限 512 KiB。

依赖边只能指向同项目已经存在的任务，因此创建接口形成有向无环图。前序任务被采用后，调度器将具体 Attempt 固定到下游；即使其余依赖尚未满足，该版本也不会随后被上游重跑替换。产出文件再次读取时验证校验值。

调度器使用独立 Tokio 任务与真实 HTTP 请求。实例并发可设为 1–64，默认 3；服务额度仍由 DeepSeek 决定。本轮只配置一个当前文字模型连接，多 Provider 路由留待实际需要。满足依赖的任务取得空位即可启动，无需等待无关任务，也不能被排在前面的依赖等待任务遮挡。

请求失败只结束当前 Attempt。手动重试创建新 Attempt，原输入、事件和成果保留；重复提交同一个请求标识不会重复执行。模型输出截断、空结果或无法解析时记为失败，不能用存在一个文件冒充完成。

PostgreSQL 会话锁保证一个实例执行器获得队列领导权。会话由执行器直接持有，进程终止后关闭并释放锁。重启把遗留的执行中记录标为中断，保留排队记录；结果不确定的付费请求不会自动重发。

## 密钥与恢复

连接配置保存在独立的 `provider_config` Docker 卷中；Linux 配置目录权限为 0700，文件为 0600，更新通过临时文件原子替换。读取接口、执行输入和日志不包含密钥。留空保存只能保留同一 API 地址的现有密钥，换地址必须重新填写。

数据库记录和文件成果使用实例持久卷，刷新页面和重建容器后保留。继承的实例备份不导出个人模型密钥；恢复到另一实例时应重新配置连接。

DeepSeek 适配使用官方的 [Chat Completions 接口](https://api-docs.deepseek.com/api/create-chat-completion/)和[当前模型入口](https://api-docs.deepseek.com/)，默认 `https://api.deepseek.com`、`deepseek-flash`，关闭思考输出并保存完整文件正文。模型名称可以修改。

## 验收与后续

隔离 PostgreSQL 和本机 HTTP 测试接口验证三请求重叠、失败隔离、重试、固定输入、前序版本引用、并发调整、进程中断与队列阻塞。浏览器检查覆盖真实表单、文件导入、图上启动、等待与失败记录和移动页面。

测试接口不证明 DeepSeek 账户连接成功。真实验收必须额外保存三个 DeepSeek 请求的起止时段、实际成果文件，以及依赖节点继续推进的记录。当前验证结果维护在[实施进度](../development/maitu-progress.md)。本轮完成后再规划代码工作区与获准工具循环。
