# 0049 脉图以 Docker 网页版继续推进

- 状态：Accepted
- 日期：2026-09-30
- 置信度：中

## 背景

用户需要实际可用的个人工具：项目历史在图上可理解，独立任务可以并行，成果能够继续用于后续工作。已经比较 Rust 与 Flutter 桌面端和 Docker 网页版；本次新仓库沿用浮点运行基础，以网页运行闭环开始推进。

## 备选方案

- Rust 后台与 Flutter 桌面客户端。
- Rust 后台与网页客户端，Docker Compose 管理运行环境。

## 决定

创建独立私有仓库 Maitu，导入浮点主线完整提交历史，其他旧项目按能力参考。首轮采用 Rust、Axum、PostgreSQL、Git worktree 和 Docker 网页版，在本机环回地址使用。

先验证现有后台与页面可启动，再接通一个真实模型与工具任务，之后扩大并行、图上操作和恢复能力。继承的前端迁移规划继续作为候选；本次启动不要求先完成整个前端重写。

新工作遵守 [AGENTS.md](../../AGENTS.md)：先归类、修改前开分支、保持提交清楚、提供实际验证，以 PR 审阅，用户明确批准后才合并。

## 影响

部署和数据命名需与旧浮点实例隔离。包名、二进制名和既有页面在迁移期间仍可使用 `fudian`，不把名称迁移夹带成领域重写。旧来源中的 Accepted 决策保留当时背景，新增范围由本记录和[首版范围](../product/maitu-scope.md)说明。

关闭浏览器不取消后台执行；电脑停止运行时，本机任务也会受影响。需要持续运行时再部署后台到常开服务器。Windows 专用工具需要独立适配，Linux 容器不能替代这一验证。
