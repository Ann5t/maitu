# Maitu 0002：把目标、任务图和真实编码连成工作流

日期：2026-10-01。状态：Accepted，已实现并通过本机验收，结果与交付状态见[实施进度](../development/maitu-progress.md)。

## 背景与选择

用户选择同时推进“想法生成任务图”和“读取仓库、修改代码、实际检查、查看并采用差异”。本轮沿用 Rust、Axum、PostgreSQL 和 Docker 网页。整体日用和旧库收拢仍按[完成路线](../product/completion-roadmap.md)独立验收。

计划节点使用已有 DeepSeek 连接生成 JSON 建议。应用验证内容、类型、依赖和循环；用户可编辑后一次性加入任务图。原建议、采用版本和节点标识一起保存，重复采用相同版本返回原节点。采用计划不会自动启动编码任务。

代码项目通过文件夹上传导入脉图管理的副本，不操作用户原目录。保留导入基线、采用版本及每次独立工作区；单个文本文件最多 1 MiB，项目最多 2,000 件、20 MiB。真实环境配置、凭据目录、Git 控制文件、构建缓存和符号链接不进入工作区。原仓库完整历史归档是后续迁移任务，不能以文件导入代替。

## 模型与检查

模型可列文件、读取、搜索、写入、替换文本，以及调用用户声明的检查。应用验证和执行工具请求，再把实际结果交回模型；每个编码节点具有独立消息序列。依据 DeepSeek 的[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)约定，后续请求保留完整 assistant 消息及 reasoning_content。计划生成使用[JSON 模式](https://api-docs.deepseek.com/guides/json_mode/)，仍由应用校验内容有效性。

检查在单独容器运行：只读挂载本次工作区，将普通代码复制到临时目录，实际运行声明的 Node、Python 或 Rust 命令，捕获退出码、输出、时段和镜像标识。检查容器没有模型密钥、Docker 接口、其他工作区或网络；限制进程数、内存、CPU、临时空间和运行时长。用户已有模型长度和思考设置保留。

应用不挂载 Docker 接口。内网检查控制器负责建立容器，使用专用授权文件；模型不能选择镜像、卷、容器配置或任意命令。检查并发与任务并发分别管理。控制器固定启动时解析的镜像标识，使用卷子目录挂载，只向容器暴露本次工作区。

请求和结果持久保存，同一编号不重复启动命令。已知容器在连接丢失后可被观察，缺失或未确定启动的容器不能自动重建。结果不确定时保留记录，人工启动新尝试。

## 成果与恢复

模型结束后应用重新运行全部声明检查。失败输出交回模型继续修正；通过才保存固定 Git 成果和差异。采用时从当前采用版本另建整合工作区，合并并再次检查；冲突、失败和现场保留。数据库采用版本为权威，采用成功和版本记录在同一事务提交。历史成果重复采用不会回退项目。

每次模型请求、文件操作、检查和整合均保存开始、结束、输入与结果。依赖固定具体成果版本，重试新建 Attempt。服务重启将遗留操作标为中断，不自动重复付费请求或未确定的进程。

既有备份覆盖数据库、成果、代码仓库、工作区和检查回执。存储清理保留新增执行恢复目录，避免按旧规则误删。执行授权和个人 API 密钥不随内容备份导出，恢复实例重新初始化授权与连接。

## 边界

检查环境提供基础运行工具；依赖未随项目提供时会真实失败，不能声称支持所有软件环境。本轮采用脉图托管副本，可导出采用版本供用户使用。直接修改外部仓库、网络安装依赖、多模型路由和完整旧库恢复验收属于后续工作。
