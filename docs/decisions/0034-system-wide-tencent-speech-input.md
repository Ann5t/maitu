# 0034：腾讯语音识别作为全系统可编辑语音输入

- 状态：Accepted
- 日期：2026-08-24
- 置信度：高

## 背景

Fudian 会频繁要求用户在电脑和手机上记录想法、与 Agent 对话、修改 Proposal 和给出审核意见。逐处实现不同的语音输入会产生不一致体验；把口述直接当成已发送命令又容易因识别错误造成错误操作。

腾讯云当前为“一句话识别”提供每月 5000 次免费成功调用，适合短语音输入，但外部额度和价格可能变化，产品不能把它当作永久不变的协议常量。

## 备选方案

- 只依赖浏览器或手机键盘自带语音输入。
- 让每个页面或 Agent 自己选择音频理解模型。
- 建立统一语音输入服务，第一版接入腾讯云语音识别。

## 决定

Fudian 提供实例级语音输入连接，第一版适配腾讯云“一句话识别”。凡是用户可以撰写普通文字的地方，包括记录想法、Session 对话、Proposal 反馈、MergeGate 意见和搜索，都使用同一麦克风交互；密码、API 密钥、恢复码和机器标识等秘密或精确结构化字段不显示语音入口。

用户结束录音后，服务器调用语音识别并把结果放回原输入框。文字始终可以编辑，绝不自动发送、接受 Proposal、批准 MergeGate 或触发其他动作。短语音可以分多次口述；更长音频作为文件导入或由以后配置的长音频能力处理。

原始录音只存在于受限临时区。识别成功并返回可编辑文字后默认删除；识别失败或取消时也按短期清理策略删除。只有用户明确选择保留原录音时，系统才把它作为来源文件导入对应想法或项目 Git/Git LFS。

腾讯凭据只保存在设置的“连接”中，由服务器侧适配器使用，不下发浏览器或进入 Agent 上下文。系统记录本实例的成功调用数并允许设置月度提醒和硬上限，首个配置可以建议 5000 次；但必须说明腾讯额度可能变化，而且同一腾讯账号在 Fudian 之外的消耗无法由本地计数得知。用户若不希望产生费用，还应在腾讯侧关闭超额付费。

语音输入是人类输入辅助，不等同于模型目录中的“音频理解”：前者只形成待编辑文字，后者供 Agent 分析项目音频内容。两者可以使用不同连接和模型。

## 影响

- 手机和桌面的主要文字入口具有一致的口述体验。
- 识别错误在用户发送前可修正，不会直接变成领域命令。
- 临时录音不会默认积累到服务器、项目历史或备份。
- 腾讯服务不可用或额度耗尽时，文字输入仍正常工作。
